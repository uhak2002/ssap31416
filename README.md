# Toss-inspired Mobile Flow Skill

Mobile MCP로 실제 안드로이드 휴대폰에 연결해 토스 앱의 안전한 조회 동선을 분석하고, 그 결과를 다른 업종의 모바일 앱·웹 설계에 재사용할 수 있도록 만든 Codex 스킬입니다.

## 과제 수행 내용

- PC와 갤럭시 실기기를 Mobile MCP로 연결
- 설치된 토스 Android 앱 실행
- 사용자 직접 생체인증 후 안전한 화면만 탐색
- 개인 이름, 잔액, 계좌번호, 기기 식별자 등 민감정보 제외
- 관찰 결과를 범용 모바일 유저 플로우 규칙으로 변환
- `SKILL.md`와 참고자료로 패키징 및 유효성 검사

## 분석한 실제 동선

```text
생체인증 → 홈 → 전체 → 검색
                    ├─ 뒤로가기 1회: 키보드 닫기
                    └─ 뒤로가기 2회: 전체 화면 복귀

전체 → 혜택 탭
```

송금, 결제, 계좌 개설, 금융상품 신청, 개인정보 수정은 실행하지 않았습니다.

## 주요 관찰 결과

- 홈은 기능 목록보다 현재 상태와 다음 행동을 먼저 보여줍니다.
- 핵심 영역은 고정 하단 내비게이션으로 유지됩니다.
- 전체 서비스 화면은 최근 사용, 추천, 카테고리, 검색을 분리합니다.
- 검색 진입 시 입력창과 키보드가 즉시 활성화됩니다.
- 시스템 뒤로가기는 키보드처럼 가장 일시적인 레이어부터 닫습니다.
- 혜택 화면은 보유 상태를 먼저 보여주고, 각 항목에는 하나의 주 행동을 둡니다.
- 광고와 추천은 사용자 보유 정보와 구분됩니다.

## 스킬 사용

```text
$toss-flow-design을 사용해 유학 컨설팅 모바일 웹의
전체 사용자 동선과 화면 구조를 설계해줘.
```

이 스킬은 토스의 상표, 문구, 이미지, 아이콘 또는 화면을 그대로 복제하지 않습니다. 요약 우선 구조, 점진적 정보 공개, 문맥 유지, 신뢰 피드백, 모바일 뒤로가기 같은 상호작용 원칙만 일반화합니다.
